# 프롬프트 스튜디오

티스토리 블로그 글 생성 도구. 카테고리별로 입력을 채우면 붙여넣기용 결과물이 완성됩니다.

- **AI 작업 실험실** — 실험 노트 컨셉 (Before/After, 실전 팁).
  입력 → 프롬프트 생성, Claude 아티팩트 환경에선 페이지 안에서 마크다운 초안까지 생성.
- **여행** — **고정 HTML 테마 + 섹션 조합(레고) 방식**.
  Hero·요약·목차·일정표·장소·맛집·카페·비용·꿀팁·FAQ·총평·CTA 중 필요한 섹션만 체크로 골라
  조합하고, 장소/맛집/카페 개수도 조절. 디자인(색·여백·카드)은 인라인 스타일로 고정돼 있어
  **티스토리 HTML 편집기에 붙여넣어도 항상 같은 모양**이 나옵니다.
  - **미리보기 탭** — 현재 선택한 섹션 구성을 실시간 렌더. 아티팩트 환경이면 `AI로 채우기`로
    실제 내용을 채운 완성 HTML을 만들고, `HTML 복사`로 티스토리에 붙여넣기.
  - **프롬프트 탭** — "이 HTML 템플릿의 구조/클래스/스타일은 그대로 두고 내용만 채워라"는
    지시문 + 템플릿을 복사해 Claude에게 붙여넣는 방식.

> 콘셉트: **디자인은 템플릿으로 고정, AI/프롬프트는 내용만 채운다.** 그래서 글마다 디자인이
> 통일되고, 버튼 색·카드 스타일 등은 `src/travel/travelTheme.ts` 토큰 한 곳에서 바꾸면 전체 반영됩니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 → dist/
npm run preview  # 빌드 결과 미리보기
```

## 배포

`npm run build` 결과물인 `dist/`는 정적 파일이라 Vercel, Netlify, GitHub Pages,
Cloudflare Pages 등 어디든 그대로 올리면 됩니다.

> `window.claude.complete`(페이지 내 초안 생성)는 Claude 아티팩트 런타임에서만
> 동작합니다. 일반 배포 환경에서는 자동으로 "프롬프트 복사" 모드로 전환돼,
> 프롬프트를 복사해 Claude에 붙여넣는 방식으로 사용합니다.

## 기술 스택
