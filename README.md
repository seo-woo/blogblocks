# 알쏭과학 스튜디오

티스토리 과학 블로그 **「매일매일 과학이야기」** 제작 도구.
평소 한 번쯤 궁금했지만 그냥 지나쳤던 것을 **짧은 호흡으로** 풀어주는 글을 하루 한 편 쌓습니다.

> 궁금쓰 — 매일 하나씩 풀어보는 세상의 궁금증 🔬

궁금증 하나를 질문으로 넣으면 다음 네 가지가 한 번에 나옵니다.

1. **기획** — 핵심 검색어, 관련 키워드, **추천 태그(유입용)**, 독자가 알고 싶은 것, 핵심 독자, 차별화 포인트, 추천 제목 3개, 메타 설명
2. **본문 HTML** — 티스토리 편집기에 그대로 붙여넣는 단순 HTML (`h2` `h3` `p` `ul` `ol` `table` `blockquote`) + 맨 아래 **참고자료**
3. **이미지 기획** — 대표 1장 + 본문 4~6장, 각각 삽입 위치·목적·생성 프롬프트·ALT
   (그림은 전부 **실사 다큐 사진** 화풍 — `src/seo/imageStyle.ts`에 고정)
4. **관련 글** — 같은 큰 주제에서 다른 질문으로 뻗어 나갈 다음 글 후보 3~5개

## 원칙

글 생성 프롬프트에 규칙으로 박혀 있습니다 (`src/seo/rules.ts`).

**글쓰기 네 기둥**
1. **쉽게 설명하기** — 중학생도 이해하게. 쉬운 말 먼저, 용어는 괄호
2. **도입부는 흥미·어그로** — 장면·반전·도발 질문·의외의 사실로 훅 (거짓 낚시는 금지)
3. **과학적 근거 확인하기** — 수치·연구·기관은 확인 가능한 것만
4. **확실한 사실과 추정 구분하기** — 확립된 사실만 단정, 추정은 완곡 표현

그 밖에
- **짧은 호흡** — 핵심 한 줄 → “라벨: 한 줄” 목록. H2 100~200자. 문단 벽 금지
- **사진 비중** — 대표 1 + 본문 4~6장. 글만 길게 이어지지 않게
- **답을 앞에서 먼저** — 도입부 다음이 바로 굵은 한 줄 결론
- **진단·치료 표현 금지** — 인체 주제는 과학·교육 콘텐츠로만
- **궁금증이 풀리면 끝** — 분량을 억지로 늘리지 않음

최신 연구·우주 탐사·건강처럼 사실 확인이 중요한 주제는 **프롬프트 탭**의 지시문을
웹 검색이 되는 Claude에 붙여넣어 확인된 정보로 쓰게 하는 쪽이 안전합니다.

## 쓰는 순서

1. **주제 설정** — 오늘의 궁금증, 궁금증 유형, 전제·범위, 이미 확인한 사실
2. **내용 자동 작성** — Gemini 키가 저장돼 있으면 페이지 안에서 초안 생성 (검색 없음)
3. **보강** — 본문 옆 `보강` 탭을 복사해 웹 검색 되는 Claude(claude.ai 또는 Claude Code)에 붙여넣으면
   사실 확인·차별화·새 Q&A까지 반영한 최종 글과 발행 전 확인 목록이 나옵니다
4. **내용 다듬기** — 사실 확인과 문장 손질. 표는 `첫 줄 = 머리글, 칸 구분 = |` 텍스트로 편집
5. **본문 탭에서 복사** — `서식 복사`(원문) / `영어 서식`(블로거) → 일반 글쓰기 붙여넣기
6. 본문의 `[이미지 N]` 줄을 실제 사진으로 교체 (이미지 탭의 생성 프롬프트·ALT 사용)

## 매일 초안 자동 생성

`topics.md`의 대기 목록 맨 윗줄을 매일 아침 07:00(KST) 하나씩 꺼내
초안을 만들고 `drafts/`에 커밋합니다 (`.github/workflows/daily-draft.yml`).
맥이 꺼져 있어도 돌아가고, 폰에서 GitHub 앱으로 확인할 수 있습니다.

만들어지는 것 — `drafts/YYYY-MM-DD-궁금증/`

| 파일 | 쓰임 |
| --- | --- |
| `초안.md` | 기획·제목 후보·이미지 기획·관련 글 + **발행 전 확인 목록** |
| `본문.html` | 티스토리 HTML 편집기에 그대로 붙여넣기 |
| `사실확인-프롬프트.txt` | 웹 검색 되는 Claude에 붙여넣어 최신 정보로 다시 쓸 때 |
| `보강-프롬프트.txt` | 이 초안을 웹 검색 되는 Claude로 사실 확인·보강할 때 (앱의 `보강` 탭과 같은 지시문) |
| `스튜디오-불러오기.json` | 앱의 `임시 저장`에서 불러와 이어서 다듬기 |

**자동 생성물은 사실 확인 전입니다.** Gemini는 웹 검색 없이 쓰므로 `보강-프롬프트.txt`를 웹 검색 되는 Claude에
붙여넣어 보강하거나, `초안.md`의 확인 목록을 처리한 뒤 발행하세요. 발행 버튼은 항상 사람이 누르는 구조입니다.
(티스토리 Open API가 2024년 2월 종료돼 자동 발행 자체가 불가능합니다.)

### 처음 한 번 설정

1. GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret
   - 이름 `GEMINI_API_KEY`, 값은 [AI Studio](https://aistudio.google.com/apikey)에서 받은 키
2. Actions 탭에서 `매일 초안` 워크플로가 보이는지 확인
3. `Run workflow`로 한 번 수동 실행해 커밋까지 되는지 확인

푸시가 403으로 막히면 Settings → Actions → General → Workflow permissions를
**Read and write permissions**로 바꿔 주세요.

> GitHub 크론은 혼잡할 때 10~30분 늦게 돌 수 있습니다.
> 저장소에 60일간 활동이 없으면 예약 워크플로가 자동으로 꺼집니다.

### 궁금증 큐 채우기

`topics.md`의 `## 대기` 아래에 한 줄씩 적습니다. 뒤 세 항목은 생략 가능.

```
궁금증 | 유형 | 분야 | 전제
왜 하품은 다른 사람에게 전염될까 | why | 인체 · 몸 | 성인 기준
```

유형은 `why` `what` `whatif` `how` `body` `compare` `truth` `daily` 중 하나(생략하면 `why`).

큐가 비면 그날은 아무것도 만들지 않고 조용히 넘어갑니다(실패로 처리하지 않음).
3개 이하로 남으면 Actions 실행 요약에 경고가 뜹니다.
초안의 `관련 글` 목록을 큐에 옮겨 적으면 잠 → 꿈 → 렘수면처럼 주제가 이어집니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 → dist/
npm run deploy   # 빌드 + Firebase Hosting 배포

GEMINI_API_KEY=... npm run draft   # 초안 1편 수동 생성 (큐에서 한 줄 소비)
```

## 구조

```
src/seo/rules.ts            공유 프롬프트 규칙(정체성·짧은 호흡·정확성) · 외부 Claude용 마스터 프롬프트
src/seo/seoAi.ts            자동 작성용 JSON 프롬프트 + 응답 파서
src/seo/seoHtml.ts          본문 HTML 렌더러 + 미리보기 문서
src/seo/imageStyle.ts       고정 화풍 블록(실사 다큐 사진) — 모든 이미지 프롬프트에 붙음
src/seo/SeoFields.tsx       궁금증 설정 입력
src/seo/SeoContentEditor.tsx 초안 다듬기 편집기
src/seo/SeoOutput.tsx       기획 / 본문 / 이미지 / 관련 글 / 프롬프트 탭
src/lib/gemini.ts           Gemini 호출 (혼잡하면 다른 모델로 폴백) — 브라우저·Node 공용
src/lib/ai.ts               브라우저용 키 보관 + window.claude 폴백
scripts/daily-draft.ts      매일 초안 생성 (큐 소비 → drafts/ 기록)
topics.md                   궁금증 큐
티스토리-마스터-프롬프트.md   앱 없이 Claude에 바로 붙여넣는 원본 지시문
src/lib/drafts.ts           IndexedDB 임시 저장 + 파일로 기기 간 이어쓰기
```
